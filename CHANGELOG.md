# Changelog

## 1.0.0 - 2026-08-13

- Initial public ARDUnia Internet Radio release.
- ESP8266 Internet radio playback.
- ST7735S 160×128 TFT interface.
- MAX98357A I2S audio output.
- Rotary encoder station navigation.
- Wi-Fi setup portal.
- EEPROM Wi-Fi credential storage.
- NTP time synchronization.
- Jalali date display.
- English display interface.
- Automatic stream reconnection.
