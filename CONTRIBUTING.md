# Contributing

Thank you for your interest in ARDUnia.

## Before submitting a change

1. Test the sketch on an ESP8266 board.
2. Keep the existing pin assignments unless a change is explicitly documented.
3. Avoid adding unnecessary libraries.
4. Keep display text in English unless a future display/font system supports Persian.
5. Describe hardware or software changes clearly.

## Pull requests

Please include:

- What changed
- Why it changed
- Hardware used for testing
- Arduino IDE / ESP8266 core version
- Any known limitations
