# Hardware Reference

## Controller
ESP8266 NodeMCU

## Display
ST7735S TFT, 160×128

## Audio
MAX98357A I2S Class-D amplifier

## Encoder
KY-040 compatible rotary encoder module

## Connections

- TFT CS: GPIO5 / D1
- TFT DC: GPIO4 / D2
- TFT RST: board RST
- TFT SCK: GPIO14 / D5
- TFT MOSI: GPIO13 / D7
- I2S BCLK: GPIO15 / D8
- I2S LRC: GPIO2 / D4
- I2S DIN: GPIO3 / RX
- Encoder CLK: GPIO12 / D6
- Encoder DT: GPIO16 / D0
- Encoder SW: GPIO0 / D3
- Volume: A0
